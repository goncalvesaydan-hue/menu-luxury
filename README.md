# Premium Online Menu

A high-end, editorial-style digital menu designed for luxury gastronomy. This project focuses on a "Mobile-First" approach with a sophisticated UI/UX that adapts seamlessly across all devices.

## ✨ Features

- **Adaptive Design:** Fully responsive layout for Mobile, Tablet, and Desktop.
- **Internationalization (i18n):** Multi-language support (Portuguese and English) with persistent selection via `localStorage`.
- **Luxury UX:**
  - **Bottom Sheet:** Fluid detail panels for mobile users.
  - **Centralized Modals:** Elegant detail views for desktop users.
  - **Staggered Animations:** High-end "fade-in" effects for menu items.
  - **Dietary Tags:** Integrated markers for Vegetarian (V) and Gluten-Free (GF) options.
- **Clean Architecture:** Vanilla JavaScript, CSS3 (Custom Properties), and semantic HTML5.

## 🎨 Design Philosophy

The project follows a **Minimalist Editorial** aesthetic:
- **Typography:** Pairing the elegance of *Playfair Display* (serif) with the modernity of *Inter* (sans-serif).
- **Palette:** Use of organic off-whites and deep ink tones to evoke the feeling of a physical high-end menu.
- **Motion:** Use of cubic-bezier transitions for a smooth, "app-like" feel.
